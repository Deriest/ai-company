# 08 — Worker Specification

**Subsystem:** Virtual Engineering Workforce  

---

## 1. Canonical Worker Roster (15 Workers)

1. **Hermes (`hermes`):** Engineering Dispatcher & Orchestrator.
2. **Rex (`rex`):** Lead Architect & System Designer.
3. **PM (`pm`):** Product Manager & Intake Coordinator.
4. **Research (`research`):** Tech Scout & Investigation Specialist.
5. **Designer (`designer`):** UI/UX Architect & Visual Designer.
6. **Documentation (`documentation`):** Tech Writer & API Spec Author.
7. **Architect (`architect`):** Infrastructure & Cloud Architect.
8. **Backend (`backend`):** API, Database & Core Logic Engineer.
9. **Frontend (`frontend`):** Web & Desktop UI Component Engineer.
10. **QA (`qa`):** Test Automation & Quality Assurance Specialist.
11. **Performance (`performance`):** Profiling, Benchmarking & Optimization Specialist.
12. **Database (`database`):** Schema Migration & SQL Query Engineer.
13. **Nexus (`nexus`):** Integration & Microservice Connector.
14. **Flint (`flint`):** DevOps & CI/CD Pipeline Automation Engineer.
15. **Security (`security`):** Code Audit, Vulnerability Scanner & RBAC Specialist.
