# 32 — Autonomous Engineering Guidelines

**Policy:** Guidelines for AI Coding Agents Operating on `AI-Company`  

---

## 1. Autonomous Rules of Engagement

1. **Verify Before Asserting:** Never claim code works, tests pass, or builds succeed without running real tool execution evidence.
2. **Never Fabricate Output:** If a tool or process fails, report the honest error directly. Never generate mock success text.
3. **Respect Project Boundaries:** Make targeted changes, run unit and integration tests after edits, and ensure typecheck passes cleanly before releasing.
