# 01 — Product Vision

**Product:** AIC-ADE
**Vision:** AI Engineering Company — Organisasi engineering otonom
**Version:** v2.3.0

---

## 1. Paradigm Shift

Traditional AI coding assistants (Copilot, Cursor, Windsurf) act as inline autocomplete or chat sidebars inside conventional text editors. User tetap menjadi operator utama — berpikir, membuat prompt, mengecek, memperbaiki prompt, mengatur semuanya.

AIC-ADE mengubah paradigma tersebut. User bukan lagi operator — user menjadi **Engineering Manager**.

```
BEFORE (AI Assistant):
User berpikir → User membuat prompt → AI menjawab → User mengecek
→ User memperbaiki prompt → AI mencoba lagi → User mengatur semuanya

AFTER (AIC ADE):
User: "Bangun sistem login untuk aplikasi ini"
→ AI Company menentukan siapa yang research, plan, implement, review, test, deliver
→ User mengelola organisasi, bukan mengoperasikan AI
```

---

## 2. What AIC-ADE IS

| Concept | Description |
|---------|-------------|
| **AI Engineering Company** | Organisasi engineering otonom dimana semua karyawan adalah AI |
| **Engineering Manager Dashboard** | User mengelola workforce, bukan mengoperasikan chatbot |
| **Structured Workflows** | Research → Plan → Build → Verify → Deliver |
| **15 Specialized Workers** | Setiap worker punya spesialisasi, tools, dan tanggung jawab |
| **Real Tool Execution** | Workers benar-benar baca file, tulis kode, jalankan command |
| **Transparent & Controllable** | User bisa melihat semua yang terjadi dan mengontrol keputusan besar |

---

## 3. What AIC-ADE is NOT

| Bukan | Kenapa |
|-------|--------|
| **AI Chatbot** | Bukan sekadar menjawab pertanyaan |
| **AI IDE** | Bukan code editor dengan AI inline |
| **AI Coding Assistant** | Bukan autocomplete atau copilot |
| **AI Copilot** | Bukan asisten yang menunggu perintah |
| **Dashboard** | Bukan monitoring tool |

---

## 4. Core Operating Principles

1. **Command Center, bukan Chat:** Chat adalah entry point dengan intent-based routing. User memberi brief, AI Company yang mengerjakan.
2. **Workers execute, bukan chat:** Workers menggunakan real tools (file read/write, shell, search) — bukan hanya generate text.
3. **Organized collaboration:** 15 workers dalam 4 departemen berkolaborasi melalui structured handoffs.
4. **Autonomous tapi terkendali:** Workers otonom dalam workspace, tapi high-impact operations butuh approval.
5. **Transparan:** Setiap keputusan, tool call, dan hasil bisa di-audit.
6. **Local-first:** Semua data di mesin user, tidak ada cloud dependency.
7. **BYOK:** User bawa API key sendiri (OpenAI, Anthropic, OpenRouter, dll).

---

## 5. Target User

- **Solo developer** yang ingin meningkatkan produktivitas
- **Small team** yang ingin AI handle routine engineering tasks
- **Technical lead** yang ingin delegate implementation ke AI
- **Startup founder** yang ingin build prototype cepat

---

## 6. Success Criteria

| Metric | Target |
|--------|--------|
| Worker tool execution rate | > 80% of tasks use real tools |
| Pipeline completion rate | > 70% of tasks complete full pipeline |
| User intervention rate | < 30% of tasks need manual fix |
| Cost per task | < $1.00 average |
| Time to first working output | < 5 minutes |
