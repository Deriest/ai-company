# 33 — Glossary of Terms

- **ADE:** Agentic Development Environment — software development platform driven by autonomous virtual AI engineering workforces.
- **AIC Platform:** The Python backend core (`aic-platform`) managing database, tasks, provider routing, and workspace files.
- **AIC IDE:** The Electron/React desktop client (`aic-ide`) serving as the visual interface for AIC-ADE.
- **BYOK:** Bring Your Own Key — user-provided API credentials for LLM providers.
- **Crafter Tier:** Model tier optimized for code implementation and refactoring.
- **Hermes:** The Dispatcher Worker acting as technical lead and engineering coordinator.
- **Project Runtime:** The root object anchoring all tasks, messages, files, and timeline telemetry for a project.
- **Sprinter Tier:** Model tier optimized for fast, low-cost tasks (reviews, unit test generation).
- **Thinker Tier:** Model tier optimized for complex reasoning, system architecture, and security auditing.
