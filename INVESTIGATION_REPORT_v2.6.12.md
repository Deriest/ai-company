#### 🔍 Likely Blank Screen Causes
Based on code analysis, potential causes for blank screen in production:

1. **Backend Startup Failure** (`ensureBackendRunning()`)
   - If Python runtime not found → backendStatus stays "error"
   - Frontend `useBoot()` hook waits forever for "healthy" status
   - Shows loading spinner indefinitely

2. **Missing Environment Variables**
   ```typescript
   if (!process.env.AIC_JWT_SECRET) {
       throw new Error("AIC_JWT_SECRET environment variable is required...");
   }
   ```
   - Production builds need `AIC_JWT_SECRET` set before launch
   
3. **Renderer Bundle Not Loading**
   - Vite build might fail silently
   - Check `dist-electron/preload/preload.js` exists
   - Verify `public/index.html` references correct bundle path

4. **Electron Main Process Crash**
   - May occur during BrowserWindow initialization
   - Requires checking Electron logs or console output

## 🔴 Issue #3: Installer Filename Pattern Mismatch

### Problem
- **Current pattern**: `aicade Setup 2.6.12.exe`
- **Expected pattern**: `AIC-ADE.SETUP.V2.6.12.exe`

### Analysis
The installer name is auto-generated by electron-builder based on `build.productName`:
```javascript
// electron-builder default behavior
fileName = `${productName}-Setup-${version}`
         = `aicade-Setup-2.6.12.exe`  // ❌ WRONG
```

### Fix Required
Same fix as **Issue #1**: Update `build.productName` to `"AIC-ADE"` in package.json

This will automatically generate correct filenames:
```
AIC-ADE Setup 2.6.12.exe           (Windows NSIS)
AIC-ADE-2.6.12.AppImage            (Linux)
aic-ade_2.6.12_amd64.deb          (Linux .deb - uses different field)
```
