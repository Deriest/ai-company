# File Analyzer

Use to analyze project file structure.

## Command

### `analyze`
Lists files by extension with counts.

Example usage:
```bash
plugin_cmd_analyze
```

Output:
```
File Analysis Report
====================
Python:   24 files
TypeScript: 18 files
Total: 62 files
```
